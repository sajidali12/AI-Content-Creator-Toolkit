# Formats, Hooks, and Storytelling

## 1. Match the idea to the format

Do not force every idea into a short vertical video. Select a format based on audience intent, complexity, access, and creator strengths.

| Format | Best suited for | Useful structures |
|---|---|---|
| Short vertical video | One quick payoff, demonstration, reaction, or story beat | Hook → context → payoff |
| Long-form video | Depth, transformation, travel, review, tutorial, documentary | Promise → setup → chapters → resolution |
| Vlog | Experience, personality, place, process, day-in-the-life | Goal → obstacles → moments → reflection |
| Tutorial | A task the viewer wants to complete | Outcome → prerequisites → steps → verification |
| Review | A decision involving a product, service, place, or experience | Criteria → test → evidence → trade-offs → verdict |
| Comparison | Choosing between options | Same criteria → evidence → who each suits |
| Podcast/interview | Expertise, perspective, story, debate | Central question → chapters → follow-ups → synthesis |
| Carousel/post | Saveable reference, framework, checklist | Problem → steps → example → summary |
| Blog/newsletter | Search intent, detail, references, durable explanation | Intent → answer → evidence → sections → next step |
| Live stream | Interaction, event coverage, real-time Q&A | Agenda → audience participation → recap |

Platform-specific lengths, features, and policies change. Verify current official platform guidance when exact limits matter.

## 2. Hook principles

A hook should:
- identify a real audience concern or curiosity
- create a clear reason to continue
- accurately represent the content that follows
- use specific details where supported
- avoid exaggerated certainty or fake stakes

Hook families:
1. **Outcome:** "By the end, you'll know how to..."
2. **Problem:** "If you keep running into [specific problem]..."
3. **Curiosity:** "I tested [thing] and found..."
4. **Contrast:** "Everyone compares X and Y, but the important difference is..."
5. **Story:** "I went to [place] for one reason, but..."
6. **Mistake:** "A common mistake when doing X is..."
7. **Question:** "Is X actually worth it for [audience]?"
8. **Myth check:** "You may have heard X. Here's what the evidence says."
9. **Demonstration:** Show the result first, then explain how it happened.
10. **Local relevance:** Connect a broad topic to a specific place or audience when genuinely useful.

Avoid empty openings such as "You won't believe this" unless the content truly earns that promise.

## 3. Short-form story structures

### Problem → solution
- Name the problem.
- Show why common approaches fail.
- Demonstrate a useful solution.
- State the limitation or next step.

### Before → process → after
- Establish a real starting point.
- Show meaningful steps.
- Reveal the outcome.
- Explain what contributed to it; avoid implying guaranteed replication.

### Myth → evidence → takeaway
- State the belief fairly.
- Present credible evidence.
- Explain nuance.
- Give a practical takeaway.

### Experiment
- State the question and method.
- Show the test fairly.
- Present observations and limitations.
- Explain what the test does and does not prove.

### Mini-vlog
- Establish place, purpose, or goal.
- Capture specific moments and obstacles.
- Use sensory details and context.
- End with a reflection or useful detail.

### Review / comparison
- State who the review is for.
- Define criteria before judging.
- Show evidence and trade-offs.
- Recommend by use case, not as a universal winner.

## 4. Long-form structure

1. Promise: what the viewer will learn or experience.
2. Orientation: context, stakes, and why now.
3. Chapters: each advances the story or answer.
4. Proof: examples, demonstrations, sources, or firsthand observations.
5. Tension: questions, obstacles, trade-offs, or surprises.
6. Resolution: answer the central question.
7. Next step: a relevant action or related content.

Avoid padding, repeated intros, and delaying the promised value.

## 5. Visual planning

For video, suggest:
- opening visual or action
- A-roll / direct-to-camera moments
- B-roll and establishing shots
- screen recordings or demonstrations
- on-screen text for key terms
- captions and readable contrast
- transitions motivated by story
- sound design only where it adds meaning

Do not prescribe a shot that the creator cannot access. Offer low-budget alternatives.

## 6. Calls to action

Choose one action that matches the content:
- save a genuinely useful reference
- share with someone who needs it
- answer a specific question
- watch a related guide
- subscribe/follow for a clear ongoing value
- visit a resource or product page when relevant

Avoid stacking several generic calls to action.

## 7. Repurposing without duplication

One core idea can become:
- short teaser
- detailed video
- carousel checklist
- blog with sources
- podcast discussion
- Q&A responding to audience questions
- behind-the-scenes follow-up

Adapt the structure and value to each format. Do not merely repost the same asset everywhere and assume context is identical.
