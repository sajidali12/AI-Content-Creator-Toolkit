# Contributing to AI Content Creator Toolkit

Thanks for helping make content strategy more useful and accessible to creators everywhere.

## Good contributions

- Improve workflows for a creator niche or format.
- Add examples grounded in realistic creator scenarios.
- Improve research verification and source quality.
- Improve accessibility, localization, and multilingual guidance.
- Add platform-specific guidance only when it is accurate, clearly scoped, and maintainable.
- Improve evaluation cases and clarify limitations.

## Before submitting

1. Explain the creator problem your change solves.
2. Keep the main `SKILL.md` focused; put detailed niche or format guidance in `references/`.
3. Avoid hardcoding fast-changing platform rules, feature limits, or algorithm claims.
4. Cite authoritative sources for factual platform guidance.
5. Do not add private user data, copyrighted scripts, scraped personal information, or unlicensed assets.
6. Include or update a test case in `evals/TEST-CASES.md`.
7. Check links and keep file names descriptive.

## Style

- Use clear, direct language.
- Prefer actionable steps over vague advice.
- Distinguish facts, assumptions, and editorial judgments.
- Avoid guarantees about views, virality, rankings, or income.
- Make workflows adaptable across countries, languages, niches, and platforms.

## Pull request checklist

- [ ] The change solves a clear creator problem.
- [ ] Instructions remain platform-aware and portable.
- [ ] Sources are linked where needed.
- [ ] Safety, privacy, copyright, and disclosure concerns are considered.
- [ ] Relevant evaluation cases are added or updated.
